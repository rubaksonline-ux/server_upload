# FileUploader - Сервер для загрузки и обмена файлами

## 🚀 Возможности

- **Загрузка файлов** через WebSocket с прогресс-баром
- **Аутентификация** (JWT) с поддержкой анонимной загрузки
- **Обмен файлами** через QR-коды и уникальные ссылки
- **Предпросмотр** изображений, видео и аудио в модальном окне
- **Разделение доступа**: админ видит все файлы, пользователь - только свои
- **Валидация файлов** по типу и размеру для разных ролей
- **Rate limiting** для защиты от злоупотреблений
- **Handlebars шаблоны** с переиспользуемыми partials
- **Безопасный CORS** с настраиваемыми доменами

## 📋 Требования

- Node.js 16+
- PostgreSQL 12+
- FFmpeg (опционально, для превью видео)

## ⚙️ Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd fileuploader
```

2. **Установите зависимости:**
```bash
npm install
```

3. **Настройте окружение:**
```bash
cp .env.example .env
```

4. **Отредактируйте `.env`:**
```env
# База данных
DB_HOST=localhost
DB_PORT=5432
DB_NAME=uploader_db
DB_USER=postgres
DB_PASS=your_password

# Приложение
APP_PORT=3000
SESSION_SECRET=your-secret-key-change-in-production

# Лимиты
ANONYMOUS_MAX_FILE_SIZE=104857600  # 100MB
USER_MAX_FILE_SIZE=524288000        # 500MB
ADMIN_MAX_FILE_SIZE=1073741824      # 1GB
```

5. **Запустите сервер:**
```bash
npm start
```

Сервер запустится на `http://localhost:3000`

## 🔐 API Endpoints

### Аутентификация
- `POST /auth/register` - Регистрация пользователя
- `POST /auth/login` - Вход
- `GET /auth/share/:code` - Получить файлы по share-коду
- `GET /auth/my-share-code` - Получить свой share-код (требуется токен)

### Файлы
- `GET /api/files` - Список файлов (свои или все для админа)
- `GET /api/files/:slug` - Метаданные файла
- `GET /files` - Страница со списком файлов
- `GET /view/:slug` - Страница просмотра файла

## 🎨 Шаблоны и Partials

Все UI компоненты вынесены в partials для переиспользования:

- **header.hbs** - Навигационная панель с меню пользователя
- **footer.hbs** - Подвал сайта
- **fileUploadModal.hbs** - Модальное окно загрузки
- **filePreviewModal.hbs** - Модальное окно предпросмотра
- **fileUploadPartial.hbs** - Форма загрузки с логикой

## 🔒 Безопасность

1. **CORS**: Настроен на конкретные домены из `.env`
2. **Rate Limiting**: Разные лимиты для анонимов, пользователей и админов
3. **Валидация файлов**: Проверка размера и типа перед загрузкой
4. **JWT токены**: Для аутентификации API запросов

## 📱 Обмен файлами

Каждый пользователь получает уникальный **share_code** (8 символов).

**Как поделиться файлами:**
1. Войдите в систему
2. Загрузите файлы
3. Скопируйте свой share_code из профиля
4. Отправьте код или QR-код другому пользователю
5. Получатель перейдёт по ссылке `/share/{code}` и увидит ваши файлы

## 🎯 Роли пользователей

| Роль | Лимит размера | Типы файлов | Rate Limit |
|------|--------------|-------------|------------|
| Anonymous | 100 MB | video, image, audio, document | 10/min |
| User | 500 MB | + archive | 30/min |
| Admin | 1 GB | Все типы | 100/min |
